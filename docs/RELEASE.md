# Release plan

## Current release

* Version: `0.4.0`
* Tag: `v0.4.0`
* Title: `FC26 ClubOS for Arch and Omarchy`

## Release notes

FC26 ClubOS 0.4.0 establishes the first proper repository release for the Arch and Omarchy focused desktop workflow.

Highlights:

* Go plus Charm first run bootstrap wizard
* Python manager, resolver, doctor, and local server layers
* Omarchy tuned Waybar and Hyprland patching
* CSV ingestion with version history and resolver queue plumbing
* SQLite checksum registry and duplicate art cleanup persistence
* Curl installer and self-healing doctor commands

## Recommended next tag flow

* `v0.4.0` for the repository baseline
* `v0.4.1` for packaging or installer fixes
* `v0.5.0` for new dashboard and resolver capabilities
